# Checklist de verificação

Antes de qualquer saída da IA circular.

## Dados qualitativos
- [ ] A citação está literalmente no trecho?
- [ ] Todo código aplicado tem uma citação que o sustenta?
- [ ] Trecho que não fala do tema ficou sem código?
- [ ] Ironia e fala ambígua foram marcadas como dúvida?
- [ ] O trecho foi lido com o contexto da fala anterior?
- [ ] Quem destoa aparece no resumo?
- [ ] A pergunta do prompt não sugeria a resposta?

## Dados quantitativos
- [ ] A unidade de contagem (pessoas, vínculos, matrículas, escolas) foi definida antes de pedir o código?
- [ ] Todo nome de arquivo e de coluna do código existe na base e no dicionário de dados?
- [ ] O código foi lido linha por linha: filtro, variável e tratamento de vazios?
- [ ] O resultado foi comparado com um número publicado, e a diferença está explicada?
- [ ] O rótulo que o código imprime descreve o que foi de fato calculado?
