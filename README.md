# Análise de dados com IA

Página de apoio sobre como usar IA para codificar entrevistas e analisar bases sem perder o controle do que a fonte diz.

- `index.html`: a página, com o caminho de trabalho (quali e quanti), erros e soluções, um exemplo conferido, ferramentas e o kit.
- `assets/`: capturas dos dois casos conferidos.
- `downloads/`: prompts por etapa, modelo de livro de códigos, planilha, checklist, instruções para projeto, skill para o Claude e conjunto de treino.

Feita para publicar pelo GitHub Pages.
